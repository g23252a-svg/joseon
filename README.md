# 동아 (東亞)

**조선에서 현대까지 — 한·중·일 삼국 대전략**

> **v1.0.2** · 빈 백 년을 채우고, 성이 안 따이던 까닭을 고친다

1392년 조선 건국에서 시작해 임진왜란 · 개항 · 식민 · 해방 · 산업화를 지나
현대까지, 육백 년을 한 판에서 다스립니다.

손전화 브라우저에서도 그대로 됩니다.

## v1.0.2 — 빈 백 년, 그리고 안 따이던 성

### ① 판의 절반이 비어 있었다

못박힌 사건의 해를 늘어놓고 사이를 재어 보니 이랬습니다.

```
1453 ─── 45년 ─── 1498      1519 ─── 71년 ─── 1590
1659 ─── 66년 ─── 1725      1725 ─── 76년 ─── 1801
1801 ─── 75년 ─── 1876
```

**1519년부터 1876년까지, 삼백오십 해에 못박힌 일이 넷뿐**이었습니다.
그 세월에 하는 일이라고는 Space를 눌러 결산을 덮는 것뿐입니다.
조선사에서 이야기가 가장 많은 대목이 이 판에서는 가장 조용했습니다.

**스물하나를 채웠습니다.**

| | |
|---|---|
| **1400 · 집집의 사병** | 왕자들이 사병으로 서로를 쳤다. 거두면 공신이 등을 돌리고, 두면 또 난다 |
| **1419 · 바다를 건너 섬을 친다** | 왜구의 근거를 칠 것인가, 포구를 열어 줄 것인가 |
| **1466 · 나누어 줄 땅이 없다** | 과전이 바닥났다. 현직에게만 줄 것인가, 곡식으로 줄 것인가 |
| **1485 · 법전을 편다** | 임금도 그 안에서 다스릴 것인가 |
| **1545 · 외척의 칼** | 두 외척이 서로를 역적으로 몬다 |
| **1555 · 남해의 큰 배** | 고을마다 지키는 방비로는 못 막았다. 비변사인가, 제승방략인가, 수군인가 |
| **1562 · 산에 든 사람들** | 도적을 잡을 것인가, 굶주림을 풀 것인가, 수탈한 수령을 잡을 것인가 |
| **1575 · 조정이 둘로 갈린다** | 자리다툼으로 시작한 것을 지금 누를 것인가 |
| **1678 · 쇠로 만든 돈** | 상평통보를 전국에 돌릴 것인가 |
| **1680 · 하룻밤에 갈아 치우다** | 환국 — 편한 손이라 자꾸 쓰게 된다 |
| **1696 · 울릉도로 간 어부** | 명 없이 바다를 건넌 어부의 말을 조정의 뜻으로 받을 것인가 |
| **1712 · 백두산 아래 비석** | 비에 적을 물줄기를 저쪽이 부르는 대로 둘 것인가 |
| **1750 · 군포 한 필** | 모자란 몫을 땅에서 걷을 것인가, 소금과 어장에서 걷을 것인가 |
| **1762 · 뒤주** | 여드레가 지났다. 조정은 말을 잃었다 |
| **1776 · 책을 모으는 집** | 서얼을 검서관으로 들일 것인가 |
| **1791 · 육의전 밖에서도 판다** | 금난전권을 거둘 것인가 |
| **1811 · 서북에서 일어난 사람들** | 성을 굶길 것인가, 그 땅의 벼슬길을 열 것인가 |
| **1834 · 한 집안이 조정을 쥐다** | 세도 — 조용한 치세를 택할 것인가 |
| **1862 · 삼정이 무너졌다** | 셋을 통째로 고칠 것인가, 수령만 벌할 것인가 |
| **1865 · 궁궐을 다시 세운다** | 원납전과 당백전을 걷을 것인가 |
| **1926 · 실려 나가는 쌀** | 쟁의인가, 야학인가, 국경 너머인가 |

**조짐도 셋 늘렸습니다** — 남해의 왜변(1555) · 서북의 봉기(1811) · 삼정의 문란(1862).
큰일이 오기 여덟 해 전부터 길잡이가 무엇이 오는지, 무엇을 해 두어야 하는지 짚습니다.

```
사건    34개 → 55개      조짐  5개 → 8개
가장 긴 구멍  76해 → 28해     사건 없는 25해 구간  8개 → 0개
```

고르는 값은 크기가 아니라 **모양**이 다르도록 맞추었습니다. 가장 좋은
갈래의 무게 평균 +8.4, 가장 나쁜 갈래 −5.5 — 어느 하나가 늘 옳으면
그것은 고름이 아닙니다.

### ② 「새 나라의 이름」은 한 번도 뜬 적이 없었다

1392년에 못박아 둔 첫 사건 — 나라 이름을 정하는, 이 놀이의 첫 물음 —
이 판이 열린 뒤로 **단 한 번도 뜨지 않았습니다.** `endTurn` 이 해를 올린
**뒤에** 사건을 보기 때문에 1392는 영영 걸리지 않았습니다.

이제 즉위 교서를 고르면 곧바로 이어집니다. 태조의 교서 → 나라의 이름.

옆에 있던 것도 하나 고쳤습니다. 아직 묻지 않은 물음이 있는데 이듬해의
작은 일이 그 자리를 **덮어써서** 소리 없이 사라질 수 있었습니다.

### ③ 압도적인 병력으로 쳐도 성이 안 따였다

성곽이 **두 번** 셈에 들고 있었습니다. `provDef` 가 `(1+성곽×0.16)` 으로
한 번 곱하고 — 성곽 9면 2.44배입니다 — 포위 걸음에서 `성곽×2.2` 를 또
뺐습니다.

```
산업화 · 요동 · 성곽 9 · 보이는 병력 8만
                     예전            지금
  8만(1배)로 치면   −6  영영 못 함락   +4.4  23해
 16만(2배)로 치면   +3.6   28해        +16.9   6해
 24만(3배)로 치면  +22.1    5해        +29.4   4해
 40만(5배)로 치면    +46    3해          +50   2해
```

28해짜리 포위는 함락이 아닙니다 — 그동안 군은 해마다 7%씩 녹으니
실제로는 영영 안 넘어옵니다. **압도적인 병력으로 쳐도 성이 안 따이는 것은
놀이가 어려운 것이 아니라 셈이 틀린 것**이었습니다.

### ④ 그런데 왜 안 따이는지 알 길도 없었다

더 나쁜 것은 이쪽이었습니다. **남의 고을을 고르면 「병력 6만」만 보였습니다.**
실제 수비는 **55만**이었는데 말입니다.

```
요동   병력 60,000  ← 판에 적히던 것
       수비 550,429  ← 실제로 셈에 드는 것
       = (수비병 60,000 + 이웃이 보태는 몫 24,000) × 지형 × 성곽 2.44 × 병종 × 기술
```

이제 **남의 고을에도 수비를 보입니다.** 그리고 치기 **전에** 셈을 보여 줍니다.

```
우리 군 150,000 · 평안북도
【요동】 수비 550,429 · 한 해 +27 · 4해면 함락        ← 누르기 전에 뜬다
```

밀고 있는 동안에도 눈금이 돕니다 — 「포위 34% · 한 해 +38 · 2해 뒤 함락」.
힘이 모자라면 붉게 「이 힘으로는 못 민다 — 군을 더 보내시오」.

### ⑤ 나누어 보낸 군은 따로 밀고 있었다

셋 가운데 **가장 큰 것**입니다. 한 성에 우리 군이 여럿 서 있어도, 군마다
**제 눈금을 따로** 밀고 있었습니다.

```
                    예전            지금
한 군 90,000        4해             4해
세 군 30,000씩(합 9만)  17해        4해   ← 같은 병력인데 네 배 넘게 느렸다
한 군 60,000        8해             8해
두 군 30,000씩(합 6만)  영영 못 함락  8해
여섯 군 15,000씩(합 9만) 영영 못 함락  4해
```

일러두기에는 「군을 더 보내면 빨라진다」고 적어 두었는데 **보낼수록
느려졌습니다.** 그리고 출정은 고을 하나에서만 뽑으므로, 사람은 자연히
이 '나뉜 모양'이 됩니다 — 압도적인 병력을 모아 놓고도 성이 안 따이는
까닭이 여기 있었습니다.

이제 한 성에 선 같은 편은 **한 무리로 묶여 함께 밉니다.** 3만 셋은 9만
하나와 똑같습니다. 띠에도 「함께 미는 군 3」이라 적힙니다.

### 그래서 얼마를 모아야 하는가

| 시대 | 성곽 | 보이는 병력 | 실제 수비 | 3해 | 5해 | 10해 |
|---|---|---|---|---|---|---|
| 조선 전기 | 4 | 20,000 | 54,269 | 50,000 (2.5배) | 32,000 (1.6배) | 20,000 (1.0배) |
| 조선 후기 | 5 | 40,000 | 201,967 | 108,000 (2.7배) | 70,000 (1.8배) | 42,000 (1.1배) |
| 식민 | 7 | 60,000 | 550,429 | 178,000 (3.0배) | 118,000 (2.0배) | 74,000 (1.2배) |
| 산업화 | 9 | 80,000 | 1,263,050 | 266,000 (3.3배) | 180,000 (2.3배) | 116,000 (1.4배) |

**보이는 병력의 두세 배**를 모으면 서너 해에 넘어옵니다. 공성전의 오랜
셈이 3 대 1이고, 조선의 국경이 1443년부터 1876년까지 사실상 그대로였던
것을 생각하면 이만하면 맞는 자리입니다. 다만 **그 두세 배를 한자리에
모을 수 있어야** 했는데, 그것이 안 되던 것이 이번에 고친 것입니다.

### ⑥ 깃발 다섯이 포개져 하나만 눌렸다

다섯 고을에서 군을 일으켜 한자리에 모으면 **깃발 다섯이 포개졌습니다.**
숫자는 서로를 덮어 뭉개지고, 눌러도 그중 하나만 잡혀 다섯을 해마다
따로따로 부려야 했습니다.

이제 **같은 자리에 선 같은 편은 한 덩어리가 됩니다** — 출정할 때도,
행군이 닿을 때도. 깃발 「4만×5」 대신 깃발 하나 「19만」이 섭니다.

### ⑦ 명령은 한 번이면 된다 — 길찾기

여태는 맞닿은 고을만 누를 수 있었습니다. 세 칸 밖의 성을 치려면 해마다
깃발을 다시 골라 다음 칸을 눌러 주어야 했습니다 — 명령이 아니라 시중입니다.

이제 **어느 고을을 눌러도** 가장 가까운 길을 스스로 찾아 해마다 한 걸음씩
갑니다. 전라도의 군에 함경북도를 누르면 「6걸음 길이다」라고 답하고 여섯
해를 스스로 걷습니다. 남의 땅에 닿으면 멈춥니다 — 거기서 싸움이 시작되는
자리이므로. 지나는 길이 남의 땅이면 돌아갈 수 있는 한 돌아갑니다.

### ⑧ 연구는 하면 뭐 하나 — 앞선 연구

시대0 마디는 넷, 합 390점입니다. 그런데 시대0은 **이백 해**입니다.
1450년쯤 넷을 다 열고 나면 1637년까지 **백여 해 동안 열 것이 하나도
없었습니다** — 연구는 해마다 쌓이는데 쓸 곳이 없으니 「기술 진흥」이
돈 먹는 헛단추였습니다.

이제 **때보다 앞서 열 수 있습니다.** 한 시대 앞은 ×1.8, 두 시대 앞은
×3.2 — 장영실이 그랬고 거북선이 그랬습니다. 세 시대 앞은 닫혀 있습니다.
조선 전기에 반도체는 없습니다.

그리고 **마디를 열 때마다 온 고을의 개발 상한이 +2** 오르고, 무예 갈래
마디는 **성곽 상한도 +1** 올립니다. 이앙법을 이루면 넓힐 논이 생기는
것이 순서입니다.

```
부지런한 판, 1392–1592 이백 해:
                        예전         지금
  아무것도 못 짓는 해     140해        114해
  열리는 기술 마디          4개          7개
  남아도는 연구          2,184점       327점   ← 연구가 실제로 쓰인다
```

### ⑨ 「놓는다 · 푼다 · 흩는다」

군 띠에 이 셋이 나란히 있었습니다. 셋 다 '풀어 놓는다'는 말이라
무엇이 무엇인지 알 수가 없었습니다 — 하나는 고르기를 그만두는 것이고,
하나는 수비병으로 되돌리는 것이고, 하나는 군사를 **영영 잃는** 것인데.

| 예전 | 지금 |
|---|---|
| 놓는다 | **선택 해제** |
| 멈춘다 | **행군 취소** |
| 군을 푼다 | **수비병으로** |
| 흩는다 | **군을 버린다** |

세로 판에서는 띠를 두 줄로 폅니다 — 한 줄에 밀어 넣으면 군 이름과
포위 셈이 서로를 밀어냈습니다.

## v1.0.1 — 다듬기

새 기둥을 세우는 판이 아닙니다. **거친 자리를 찾아 없애는 판**입니다.
1.0.0 을 손에 쥐고 큰 판과 손전화를 오가며 훑었더니, 여섯 세기를 굴리는
동안 눈에 밟히던 것들이 줄줄이 나왔습니다.

### 손전화에서 지도의 절반이 까맸다

가장 큰 것부터. 구워 두는 지도판(`MAPBASE`)의 크기를 **화면 크기**로
잡고 있었습니다. 넓은 판(1280×720)에서는 지도(888×480)가 넉넉히 들어갔지만
**세로 판은 470 폭**입니다 — 지도 오른쪽 426픽셀이 통째로 잘려 나갔습니다.

그래서 손전화로 열면 동해 건너부터 새까맸습니다. 일본이 없었습니다.

```
       구워 둔 판          지도가 필요한 크기
넓은 판  1280 × 720   ✓    896 × 542
세로 판   470 × 980   ✗    896 × 542   ← 오른쪽 426이 없다
```

판 크기는 화면이 아니라 지도가 정합니다. 한 줄 고치니 손전화에서도
넓은 판과 똑같은 지도가 섰습니다. 덤으로 돌려 세울 때마다 다시 굽던 일도
없앴습니다 — 이제 판이 바뀌어도 다시 구울 까닭이 없습니다.

### 무너지는 해에 지도가 붉은 벽이 되었다

한 해에 고을 여럿이 한꺼번에 넘어가면 — 무너지는 판에서는 흔한 일입니다 —
「평안북도 함락」「함경남도 함락」「경기도 포위」가 **같은 자리에 포개져**
읽을 수 없는 붉은 덩어리가 되었습니다. Space 로 해를 빨리 넘길 때도
마찬가지였습니다.

셋을 두었습니다. **여덟 줄까지만** 살려 두고, 뒤에 오는 글은 **조금씩 늦게**
띄우고, 그리는 때에 화면에서 겹치면 **위로 밀어 올립니다**. 이제 한 해에
다섯 곳이 넘어가도 다섯 줄이 차례로 읽힙니다.

### 조정에 105세가 앉아 있었다

신하는 일흔넷을 넘긴 뒤에도 **해마다 5%씩만** 물러났습니다. 일흔넷을
넘기고도 스무 해를 더 앉아 있는 셈이라, 1472년 조정에 **105세 · 97세 · 94세**가
줄지어 있었습니다. 조선의 법은 일흔에 치사(致仕)였습니다.

이제 나이를 먹을수록 가파르게 오릅니다 — 예순 2%, 일흔 10%, 여든 55%.

```
        가장 늙은 신하   가운데
예전     105세           74세
지금      67~75세        50~65세
```

떠나는 말도 나이를 따릅니다. 「늙어 물러나」 「병으로 물러나」 「세상을 떠나」.

그리고 **사화로 쫓겨난 사람이 이듬해에 다른 고을 수령으로 돌아왔습니다.**
사화가 아니라 자리바꿈이었습니다. 이제 **귀양을 갑니다** — 대여섯 해에서
열두 해 동안 다시 쓰이지 않고, 신하 판에 「귀양 7해 남음」이라고 붉게 남습니다.

### 처음 잡은 사람에게 — 일러두기

판 위의 설명은 여태 **커서를 얹어야 나오는 쪽지**뿐이었습니다.
손가락에는 얹을 자리가 없습니다 — **손전화로 잡은 사람은 아무 설명도 못 본 채**
눈금 스무 개와 단추 열댓 개를 마주했습니다.

읽을 것을 따로 두었습니다. 제목 화면과 메뉴에서 열립니다. 네 쪽입니다.

| 쪽 | 무엇이 |
|---|---|
| **처음** | 무엇을 하는 놀이인가 · 누르는 법 · 글쇠 · 길잡이를 따라가면 된다 |
| **한 해** | 정무와 별칙 · 고을에 내리는 여섯 명령 · 조정의 일 · 결산과 사건 |
| **나라** | 고을 눈금 읽는 법 · 수령과 붕당과 사화 · 민심과 정통 · 임금 · 살림 |
| **밖** | 사신·통상·동맹·이간·중재 · 출정과 야전과 포위와 군량 · 점령지 |

그리고 **첫 세 해 동안은 길잡이 맨 위에** 「처음이라면 일러두기부터」가
섭니다. 만들어 두어도 있는 줄을 모르면 없는 것과 같습니다.

### 손가락에 넉넉하게

검사 하나가 **아무것도 검사하지 않고 있었습니다.** 단추를 이름으로 찾아
크기를 재는 검사였는데, 단추가 누를 자리에 **이름을 붙이지 않아** 늘 빈
목록을 재고 「모두 넉넉」이라 답하고 있었습니다.

이름을 붙이고 다시 재니 이렇습니다.

```
지형·정치   19.1px      한반도·동아시아  19.9px
보기·세력   18.3px      국정~기록 탭      21.6px
```

애플은 44, 구글은 48을 권합니다. **그림은 그대로 두고 누를 자리만**
사방으로 넓혔습니다 — 작은 판에서만. 이제 모두 28px을 넘고, 단추
한가운데를 눌렀을 때 이웃이 대신 잡히지 않는지도 함께 잽니다.

### 그 밖에 고친 것

- **짧은 화면에서 「고을 바로 선택」 상자가 오른쪽 판을 먹었습니다.** 상자는
  화면 크기로 자라고 판은 배율로 줄어드니, 360×640에서는 못박아 둔 62 대신
  **113**을 덮고 있었습니다. 이제 실제로 덮는 깊이를 재어 비웁니다
- **제목 화면**의 지도 배경이 세로 판에서는 위쪽 띠 하나뿐이고 아래는
  새까맸습니다. 배경만큼은 화면 전체로 넓혀 깝니다 (누를 수도 없는
  손잡이가 옅게 떠 있던 것도 걷었습니다)
- **줄 첫머리에 마침표가 홀로 서던 것**을 고쳤습니다(금칙). 한 글자씩 끊어
  넘기다 보면 「…이 판의 성적이다」 다음 줄이 「. 고을을 다 잃으면」으로
  시작했습니다
- 길잡이가 **나라의 민심과 정통**이 바닥날 때도 짚어 줍니다. 고을마다의
  어지러움은 짚으면서 그 뿌리는 말해 주지 않았습니다
- 남의 고을을 골랐을 때 뜨던 **「수령 없음」**을 걷었습니다 — 남의 조정에
  우리가 수령을 둘 일은 없습니다

### 균형은 그대로

씨앗 열둘로 다시 재었습니다.

## v1.0.0 — 군대가 판 위에 선다

여태 **「친다」는 단추 하나**였습니다. 누르면 주사위가 굴러 고을이 즉시
넘어왔습니다. 전선도 없고, 군대가 어디 있는지도 없고, 비운 자리도 없었습니다.
**전쟁이 판단이 아니라 손가락**이었습니다.

이제 군사를 일으키면 **판 위에 말이 하나 섭니다.**

### 출정 · 행군 · 포위 · 야전

| | |
|---|---|
| **출정** | 고을의 병력에서 수비병을 남기고 야전군을 세웁니다. 판 위에 깃발이 섭니다 |
| **행군** | 군을 고르면 맞닿은 고을이 빛납니다. 누르면 그리로 갑니다 — 한 해에 하나씩 (바닷길·산길은 두 해) |
| **포위** | 남의 성에 닿으면 포위가 시작됩니다. 성곽이 높을수록 오래 걸립니다 |
| **야전** | 남의 군과 마주치면 그 자리에서 붙습니다. 진 쪽은 흩어집니다 |
| **소모** | 남의 땅에서는 해마다 7%씩 줄고, 군량이 국고를 먹습니다 |

실제로 재 보면 이렇습니다.

```
평안북도에서 18,000을 일으켜 요동으로 (요동이 지키는 힘 29,845)

1392  요동 도착  16,740  포위 18%
1394               14,478  포위 51%
1396               12,522  포위 81%
1398   함락         9,406       ← 일곱 해, 사람 절반
```

**일곱 해와 병력 절반**입니다. 단추 한 번이 아니라 한 임금의 치세를 건 사업입니다.

### 이웃도 걸어 다닌다

명과 일본도 같은 규칙으로 군을 세우고 움직입니다. **즉시 점령은 없어졌습니다** —
한쪽만 걸어 다니고 다른 쪽은 순간 이동하면 그것은 같은 놀이가 아닙니다.

그래서 이제 **내 성이 포위당하는 것이 보입니다.** 붉은 고리가 성 둘레에서
차오르고, 길잡이가 「평안남도가 포위당했다 38%」라고 알립니다. 군을 보내
야전으로 걷어 내거나, 축성과 모병으로 버팁니다.

### 균형이 어떻게 달라졌나

| 두는 법 | 끝난 해 | 점수 | 최대 고을 | 출정 | 빼앗음 | 잃음 |
|---|---|---|---|---|---|---|
| 넘기기만 | 1768 | 24 | 16 | 0 | 0 | 8 |
| 수령만 | 1865 | 206 | 16 | 0 | 0 | 14 |
| **두루 챙김** | **2025 완주 6/6** | **1231** | 16 | 0 | 0 | 2 |
| 정복 | 2025 | 739 | 17 | 6 | 4 | 4 |
| 밀어붙임 | 2025 | 767 | 17 | 18 | 13 | 6 |

**최대 고을이 38에서 17로 내려왔습니다.** 예전에는 밀어붙이면 반도 밖으로
쭉쭉 뻗어 나갔는데, 이제는 열세 곳을 뺏고 여섯 곳을 내주며 육백 년을
밀고 당깁니다. **정복이 통일이 아니라 국경 전쟁**이 되었습니다.

그러면서도 **두루 챙기는 판이 여전히 가장 높습니다**(1231 대 767).
싸움은 이제 값이 비싼 길입니다.

### 그 밖에

- 군은 지도 아래 **띠**에서 부립니다 — 아래 판에는 수치 줄과 명령 줄이
  이미 꽉 차 있어 자리가 없었습니다. 세로 판에서도 같은 자리입니다
- 길잡이가 **멈춰 선 군**과 **포위 중인 성**과 **포위당한 내 성**을 짚어 줍니다
- 결산에 **야전군 군량**이 한 줄 늘었습니다
- 「평안남도이」 같은 조사를 하나 더 고쳤습니다

0.9.3 세이브를 그대로 읽습니다.

## v0.9.3 — 실록

끝나면 **점수표 하나**가 떴습니다. 육백 년을 두고 나서 받는 것이 그것뿐이면
그 육백 년이 어디로 갔는지 알 수가 없습니다.

해마다 한 줄씩 적어 두었다가, 마지막에 **실록 한 권**으로 폅니다.
네 쪽입니다.

### ① 마침

어떻게 끝났는가, 몇 점인가, 기록에서 몇째인가. 시대별 성적표.

### ② 강토

**1392년 지도와 마지막 해 지도를 나란히** 놓습니다. 남의 땅은 눌러 두고
조선만 밝게 칠하므로, **무엇을 얻고 무엇을 잃었는지 한눈에** 보입니다.

| | 1392 | → | 끝 |
|---|---|---|---|
| 고을 | 16곳 | | 2곳 |
| 인구 | 611만 | | 477만 |
| 기술 | 10 | | 399 |

그리고 **육백 년의 발자국** — 십 년마다 찍어 둔 고을 수와 인구를
한 줄의 그래프로 그립니다. 언제 커졌고 언제 무너졌는지가 선으로 남습니다.

### ③ 치세

지나온 **모든 임금**과 사관이 적은 한 줄.

```
36대  ·  성세 2 · 치세 8 · 평세 25 · 망조 1

태종  1400–1418  18년 · 교서 「곳간을 채운다」          망조
      강토가 4고을 줄었고 성 4를 내주었으며 학문에 1마디를 보태었고
      사화가 2차례 일어났고 백성은 그럭저럭 살았다.
선조  1567–1608  41년 · 교서 「어진 정치를 편다」       평세
      학문에 1마디를 보태었고 사화가 2차례 일어났고
      「임진왜란」의 문턱을 넘었고 백성이 배불렀다.
```

### ④ 남은 것

이 판이 **무엇을 한 판이었는지**가 여기서 드러납니다.

```
조정이 한 일    개간 109번 · 장 33번 · 축성 0번 · 모병 0번 · 진휼 0번
                기술 마디 9 / 20
싸움            전쟁 7번 · 전쟁으로 보낸 해 39해 (가장 길게 9해)
                빼앗은 고을 0곳 · 잃은 고을 14곳 · 사화 5번
이웃            청 적대 −66 · 전쟁 5번 / 메이지 무덤덤 −10 · 전쟁 2번
                처음 통상을 연 해 — 끝내 열지 않았다
하지 않은 일    · 통상 조약을 한 번도 맺지 않았다
                · 동맹을 한 번도 맺지 않았다
                · 남의 고을을 한 곳도 치지 않았다
```

**하지 않은 일도 이 판의 얼굴입니다.** 위 판은 삼백 년을 개간만 하다가
성 한 번 쌓지 않고 열네 고을을 내준 판입니다 — 점수표 한 줄로는
알 수 없던 것입니다.

- 실록은 저장에 함께 들어갑니다 — 불러와도 그대로 있습니다

## v0.9.2 — 길이 보인다

특산과 통상은 **숫자로만** 있었습니다. 인삼을 팔아도 지도에는 아무 일이 없고,
세곡이 한성으로 올라와도 그 길이 어디로 나 있는지 알 수 없었습니다.
나라가 **무엇으로 이어져 있는지**가 안 보이면, 고을 하나를 잃는 것이
장부에서 한 줄 빠지는 일로만 보입니다.

길 셋을 그립니다.

### 조운길

도읍을 뿌리로 이웃을 따라 나무를 세웁니다. 고을마다 거둔 것이 그 길을 타고
**한성으로 흘러갑니다** — 낟알이 길 위를 굴러가는 게 보입니다.

- **도읍에 가까운 줄기일수록 굵습니다** — 잎에서 뿌리로 흐름이 더해지니까요
- **점령지의 길은 가늡니다** (세가 반만 걷히므로 0.45배)
- **어지러운 고을의 길은 흐려집니다**
- 바닷길(전라 ↔ 제주)은 **점선**입니다

### 교역로

통상 조약을 맺으면 지도에 길이 그어집니다.

| | 어디서 어디로 |
|---|---|
| 명 | 평안북도 → 요동 · 황해도 → 산동 |
| 일본 | 경상남도 → 대마도 · 전라도 → 규슈 |

**나가는 물건은 초록, 들어오는 돈은 금빛**으로 서로 엇갈려 흐릅니다.
전쟁이 나면 길이 **붉게 끊어집니다.**

### 철길

**식민 시대(1910)부터** 굵은 줄기가 철길이 됩니다. 침목이 놓이고 빛깔이
쇠빛으로 바뀝니다. 실제로 경부선·경의선이 놓인 무렵입니다.

### 고을을 잃으면 길이 끊어진다

길은 **도읍에서 뻗어 나간 나무**입니다. 그러니 중간의 고을을 잃으면
**그 너머가 통째로 끊깁니다.** 경상도와 전라도를 내주면 남쪽 길과 제주 뱃길,
일본과의 교역로가 한꺼번에 사라집니다 — 장부에서 세 줄이 빠지는 것이 아니라
나라의 절반이 지도에서 떨어져 나가는 것으로 보입니다.

**빠르기.** 한반도 전체가 큰 판 17~21ms, 세운 손전화 10.5~13ms 입니다.
침목은 3배 이상 당겼을 때만 놓습니다 — 멀리서는 선 굵기로 충분합니다.

0.9.1 세이브를 그대로 읽습니다.

## v0.9.1 — 시대의 얼굴

**1392년 지도와 1988년 지도가 초가 지붕 말고는 똑같았습니다.** 육백 년을
지났다는 실감이 나려면 지도도 함께 늙어야 합니다.

자리는 건드리지 않습니다. **같은 집이 시대를 따라 얼굴만 바꿉니다.**

| 시대 | 지붕 | 성벽 | 그 밖에 |
|---|---|---|---|
| 조선 전기·왜란 | 초가 62% · 기와 | 온전한 고리와 망루 | |
| 조선 후기 | 초가 42% | 그대로 | |
| **개항** | 초가 22% · **벽돌 양옥** | 그대로 | 돛배가 **연통 단 기선**으로 |
| **식민** | 초가 8% | **헐린다** — 끊긴 토막과 문루만 | **공장 굴뚝**이 선다 |
| 해방·산업화·**현대** | **평지붕 콘크리트** | 자취만 | 창에 **불이 켜지고**, 도읍에 높은 건물 |

성곽은 셈에서는 그대로 값을 합니다 — **규칙은 건드리지 않고 그림만** 바꿉니다.
실제로 개항 뒤 성벽이 헐렸던 그대로입니다.

논 빛깔도 시대를 탑니다. 도읍에는 산업화 뒤로 궁 뒤편에 높은 건물이 서고,
창문 몇은 불이 꺼져 있습니다.

**빠르기.** 창과 굴뚝이 늘었는데도 한반도 전체가 조선 전기 20.6ms · 현대 14.5ms,
세운 손전화는 11~13.5ms 로 60프레임입니다. 지붕을 종류별로 한 길(path)에 모아
칠하는 덕입니다.

0.9.0 세이브를 그대로 읽습니다.

## v0.9.0 — 자라는 고을

`글자만 있고, 애니메이팅이라든지 모션이라든지, 도시가 발전 커져가는 모습이라든지,
좀 동적인 모셔닝이 없으면 재미있겠냐` — 맞는 말이었습니다.

**개발 4인 고을과 40인 고을이 똑같이 생겼습니다.** 다각형에 빛깔을 칠하고 이름을
얹은 것이 전부였으니, 삼백 해를 개간하고 축성해도 지도는 첫해와 같은 그림이었습니다.
눈금이 오르는 것을 숫자로만 알 수 있으면 그것은 **장부이지 지도가 아닙니다.**

### 고을이 지도 위에 선다

이제 고을마다 마을을 그립니다. 무엇이 몇 개 서는지는 **지금 눈금이 정합니다.**

| 눈금 | 지도 위에서 |
|---|---|
| **개발 · 인구** | 마을 전체의 크기, 초가와 기와집의 채수 |
| **성곽** | 성벽의 두께와 반지름, 망루의 수, 남문의 문루 |
| **농지** | 마을 둘레의 논 뙈기 — 이랑까지 |
| **상업** | 저자의 깃발 (바람에 흔들립니다) |
| **병력** | 성 안에 선 창대와 기 |
| **도읍** | 이중 처마의 궁 지붕과 숨 쉬듯 뛰는 빛 |
| **어지러움 55↑** | 고을을 감도는 붉은 기운 |

자리는 고을 이름을 씨앗으로 **한 번만 정해 둡니다.** 몇 채를 그릴지만 지금
눈금에서 가져오므로, 자리가 늘 같아서 **「자란다」로 보입니다.**

```
마을   개발 3  · 농지 4  · 성곽 0  → 지붕 셋, 논 한 뙈기
고을   개발 12 · 농지 14 · 성곽 2  → 성벽이 서고 망루 넷
큰고을 개발 24 · 농지 26 · 성곽 4  → 저자의 깃발, 논이 마을을 두른다
도회   개발 38 · 농지 38 · 성곽 7  → 성벽 두 겹 두께, 망루 아홉, 창대가 늘어선다
```

### 지은 것이 솟아오른다

명령을 누르면 **그 자리에서 실제로 무엇이 일어납니다.**

| 누르면 | 지도에서 |
|---|---|
| 개간 | 논이 한 뙈기 **자라 오르고** 흙먼지가 인다 |
| 장을 연다 | 저자에 깃발이 하나 **선다** |
| 축성 | 망루가 땅에서 **솟는다** |
| 모병 | 창대가 하나 **오른다** |

한 해를 넘기면 지도 위로 **빛이 한 번 지나갑니다.**

### 가만히 두어도 움직인다

- 굴뚝의 연기가 피어올라 흩어집니다
- 저자의 깃발과 군기가 바람에 흔들립니다
- 바닷가 고을의 배가 물결에 오르내립니다
- 도읍의 빛이 숨 쉬듯 뜁니다

화소를 세어 재 보았습니다 — **가만히 두어도 지도의 1.1%가 늘 움직이고**,
한 해를 넘기면 11.5%가, 성을 쌓으면 39.7%가 바뀝니다.
예전에는 **0%** 였습니다. 손 대기 전에는 완전한 정지 그림이었습니다.

### 다가갈수록 자세해진다

한반도를 통째로 보는 눈에 논두렁이 보일 까닭이 없습니다. 배율에 따라 나눕니다.

| 배율 | 보이는 것 |
|---|---|
| ~1.6배 | 크기만 보이는 덩어리 |
| 1.6~4배 | 지붕 · 성벽 · 망루 · 궁 · 연기 |
| 4배~ | 논 · 저자 · 창대 · 배 |

두 픽셀짜리 마을에는 아무것도 그리지 않습니다.

**빠르기.** 처음에는 한반도 전체에서 한 프레임이 31ms 였습니다(60프레임은
16.7ms 안에 끝나야 합니다). 배율로 나누고, 집과 논을 빛깔별로 한 길(path)에
모아 세 번만 부르게 고쳐 **19.5ms** 가 되었습니다 — 마을을 그리기 전이 16.9ms
였으니 마을 값은 2.6ms 입니다. 세운 손전화에서는 13.2ms 로 60프레임입니다.

### 그 밖에

- 마을은 **뭍에만 섭니다.** 처음에 이름표 자리를 썼더니 개성이 바다 한가운데에
  성을 쌓았습니다. 이제 고을의 실제 자리에 서고, 해안선으로 잘라 냅니다.
- 도읍의 금빛 점을 **가까이서는 걷습니다** — 애써 그린 궁 지붕을 제가 덮었습니다.

0.8.0 세이브를 그대로 읽습니다.

## v0.8.0 — 임금과 치세

`뭔가 게임이 몰입력과 흡입력이 있어야 하는데, 크게 재미를 느낄 만한 요소가
부족하다` — 맞는 말이었습니다. 규칙은 늘었는데 **판에 사람이 없었습니다.**

다스리는 것은 「조정」이라는 이름 없는 무엇이었고, 육백 년이 한 덩어리로
흘렀습니다. 마디라고는 시대 여덟 개뿐이라 1392년의 한 해와 1700년의 한 해가
똑같이 생겼습니다. 여섯 단추를 육백 번 누르는 동안, **내 판을 남의 판과
구별해 주는 것이 아무것도 없었습니다.**

두 가지를 넣었습니다. **누가 다스리는가**와 **무엇이 다가오는가**입니다.

### 임금 스물일곱

실제로 앉았던 임금을 그 해에 그대로 앉힙니다. 저마다 잘하는 것과 못하는 것이
있고, 그것이 규칙에 그대로 듭니다.

```
세종    1418   성세    연구 +45%  국고 +5%  민심 +0.7/년  정통 +0.7/년
        집현전의 불이 꺼지지 않는다. 백성이 쓸 글자를 만들고 있다.

연산군  1494   폭정    국고 −18%  민심 −1.6/년  정통 −1.2/년  당쟁 거세다
        사초를 문제 삼아 선비를 베었다. 곳간이 잔치로 빈다.

영조    1724   탕평    연구 +15%  국고 +10%  민심 +0.9/년  당쟁 잦아든다
        탕평비를 세웠다. 오십이 년을 앉아 붕당을 눌러 간다.
```

같은 손으로 같은 판을 두어도 **세종 밑에서와 연산군 밑에서가 다릅니다.**
1910년 뒤에는 임금이 없으므로 열두어 해마다 바뀌는 「대(代)」로 잇습니다.

### 즉위 교서 — 판에서 가장 자주 하는 선택

임금이 설 때마다 첫 글을 내립니다. **그 치세가 끝날 때까지 갑니다.**

| | |
|---|---|
| 어진 정치를 편다 | 민심 ↑ · 국고 −8% · 연구 −15% |
| 군을 기른다 | 수비 ↑ · 국고 −10% · 곡식 −6% |
| 학문을 일으킨다 | 연구 +35% · 민심 −0.3 |
| 곳간을 채운다 | 국고 +14% · 민심 −0.6 |
| 붕당을 누른다 | 당쟁 열기 ↓ · 신하 충성 −1 |
| 농사를 살핀다 | 곡식 +12% · 인구 ↑ · 장사 −8% |
| 이웃과 사귄다 | 침공 위험 ↓ · 수출 +25% · 정통 −0.3 |

임금의 결에 맞는 둘에 딴것 하나를 섞어 셋을 내밉니다 —
세종에게 「군을 기른다」만 내밀지 않습니다.
한 판에 스물일곱 번 고르게 되니, **이것이 이 놀이에서 가장 자주 하는 선택**입니다.
고르기 전에는 한 해를 넘길 수 없고, Esc 로 도망칠 수도 없습니다.

### 사관의 붓

승하하면 사관이 그 치세를 적습니다. 숫자가 아니라 한 줄로 적습니다.
그 치세 동안 실제로 일어난 것만 들어갑니다.

```
태조    1392–1398   6년   치세   조정의 명분이 섰으며 백성은 편안하였다.
태종    1400–1418  18년   평세   강토가 1고을 줄었고 성 1을 내주었으며
                                한 차례 전쟁을 치렀으며 창고가 비지 않았다.
세종    1418–1450  32년   망조   강토가 3고을 줄었고 성 3을 내주었으며
                                사화가 2차례 일어났고 전쟁이 2차례 있었으며 …
```

**같은 세종이 판마다 다릅니다.** 씨앗 셋을 돌려 보면 평세 · 난세 · 망조가
갈립니다 — 그 서른두 해를 어떻게 두었느냐의 몫입니다.
등급은 나라의 크기가 아니라 **그 사람이 맡은 동안 무엇이 달라졌는가**로만
매기고, 다섯 해를 못 채운 임금에게는 성세도 망조도 씌우지 않습니다.

지나간 치세는 **기록 탭 맨 위**에 쌓입니다. 판을 돌아볼 때 남는 것입니다.

### 다가오는 일

이 판에서 큰일은 늘 갑자기 왔습니다. 1592년에 화면이 하나 뜨고, **그제야**
남해안에 성이 없다는 것을 알게 됩니다. 그때는 이미 늦었습니다.

못박힌 큰일 다섯에 그림자를 미리 드리웁니다.

| | 몇 해 전부터 | 무엇을 해 두라고 하는가 |
|---|---|---|
| 왜란 (1592) | 18해 | 남해안 고을의 성과 병력. 일본과의 사이 |
| 북쪽의 새 나라 (1636) | 14해 | 서북의 성. 명과의 사이를 어디까지 지킬지 |
| 열리는 문 (1876) | 12해 | 기술 마디 |
| 국권 (1910) | 12해 | 정통과 군사 |
| 전란 (1950) | 6해 | 곳간과 군사 |

위 표시줄에 **「왜란까지 12해」** 가 서고, 「이번 해에 할 일」 맨 위에 올라오며,
가까워질수록 붉어집니다. 누르면 지켜야 할 고을로 갑니다.
**그 열두 해가 각각 다른 해가 됩니다 — 준비하는 해입니다.**

### 고친 것

- **임금의 학문이 기술을 찍어 내던 것**을 고쳤습니다. 처음에는 해마다 국가
  기술을 바로 얹었더니, 아무것도 하지 않는 판이 육백 년 만에 기술 1467에
  이르렀습니다. 기술은 수비에 그대로 곱해지므로(1+기술/220) 가만있는 나라가
  일곱 배로 단단해져 아무도 이기지 못했습니다. 이제 학문은 **연구**를 밀 뿐,
  마디는 사람이 열어야 열립니다.
- 임금 이름표가 위 표시줄의 **국고를 덮던 것**을 고쳤습니다. 눈금이 이제 왼쪽
  글월이 끝난 자리에서 시작합니다.
- 명과 일본이 **서로 손을 잡고 있으면 조선은 어느 쪽과도 동맹할 수 없습니다** —
  이미 짝이 있는 사람에게 형제를 청할 수는 없습니다.

균형은 그대로입니다 (각 8판) — 넘기기만 1678년 · 수령만 1639년 ·
**두루 챙김 2025년 완주 8/8** · 정복 1871년 · 밀어붙임 1748년.

## v0.7.0 — 이웃끼리도 사이가 있다

여태 **사이라는 것은 조선이 남을 보는 눈 하나뿐**이었습니다.
명과 일본은 서로 땅을 뺏고 뺏기면서도 아무 사이가 없었습니다.
그래서 판이 늘 「조선 대 둘」로만 굴러갔고, 조선이 할 수 있는 일도
둘 중 하나를 달래는 것뿐이었습니다.

이제 그 둘에게도 사이가 있습니다.

### 명 ↔ 일본

외교 탭 아래에 줄이 하나 늘었습니다. 조선을 끼우지 않은 줄입니다.

| 이웃끼리 | 조선에게 |
|---|---|
| **서로 전쟁** | 둘 다 군사를 그쪽으로 돌립니다. 조선을 향한 발길이 뜸해집니다 — **틈** |
| **서로 동맹** | 조선이 사이에 끼입니다. 둘 다 더 나오고, 서로 원병까지 보냅니다 — **위기** |
| 서로 통상 · 휴전 | 조용합니다 |

둘의 사이는 시대가 갈수록 나빠지고(같은 바다에서 부딪칩니다),
서로 제 땅을 쥐고 있으면 더 나빠지고, **조선이 커질수록 좋아집니다.**
열여덟 고을을 넘어서면 옆에서 셈이 달라집니다.

**임진왜란이 열리면 두 나라는 실제로 맞붙습니다** — 명이 군사를 냈던 그대로.

### 이간과 중재

| | 값 | 하는 일 |
|---|---|---|
| **이간** | 180전 · 정무 2 | 둘 사이를 14~24 벌립니다. **들킬 낌새 8~34%** — 들키면 양쪽과의 사이 −16, 정통 −5 |
| **중재** | 320전 · 정무 2 | 다섯 해 동안 둘이 손을 놓을 낌새가 크게 늡니다 (**싸움이 이어진 해 6.0 → 3.3**). 정통 +8, 양쪽과의 사이 +12 |

벌리는 쪽이 싸고, 말리는 쪽이 명분을 남깁니다.
외교에 밝은 신하가 있으면 잘 벌리고 덜 들킵니다.

둘 중 어느 쪽도 공짜가 아닙니다. **말리면 둘이 다시 조선을 봅니다** —
정통과 사이를 얻는 대신 숨 돌릴 틈을 내주는 셈입니다.

### 크게 먹은 값

여태 크게 먹은 값은 **어지러움뿐**이었습니다. 밖에서는 아무 일도 없었습니다.
이제 조선이 커지면 두 나라가 손을 잡습니다.

같은 손을 쓰되 이간만 더한 두 판을 견주면 (각 8판, v0.8.0 기준):

| 두는 법 | 끝난 해 | 점수 | 최대 고을 | 이웃이 **서로 동맹**한 해 |
|---|---|---|---|---|
| 밀어붙임 | 1748 | 263 | 38 | **139** |
| 이간질 | 1691 | 191 | 36 | **12** |

이간은 연합을 확실히 막습니다(139해 → 12해). 다만 해마다 정무 둘과 값을
치르는 만큼, **그 값이 늘 남는 것은 아닙니다** — 언제 벌릴지가 손입니다.
(v0.7.0에서는 이간 쪽이 점수도 앞섰습니다. v0.8.0에서 임금의 재주와 교서가
붙으면서 밀어붙이는 판이 더 오래 버티게 되어 뒤집혔습니다.)

  (삼백 해에 14번 → **4번**).
- **쫓겨난 사람이 그 자리를 도로 맡던 것**을 고쳤습니다.
  「황희가 쫓겨났다. 충청북도는 황희가 맡는다」

## v0.6.0 — 손전화와 지켜지는 약속

두 가지가 걸렸습니다. **손전화에서는 판이 0.3배로 줄어 글씨가 뭉개졌고**,
**동맹을 맺은 이듬해에 상대가 그 약속을 깨고 쳐들어왔습니다.**

### 손전화

판 하나를 늘였다 줄였다 하는 대신, 화면의 생김새를 보고 **세 벌 중 하나**를
씁니다. 줄이는 게 아니라 다시 짜는 것이라 글씨 크기가 그대로 남습니다.

| 화면 | 판 | 지도 | 배치 |
|---|---|---|---|
| 여느 화면 | 1280×720 | 888×480 | 지도 왼쪽 · 판 오른쪽 |
| 작은 창 · 눕힌 손전화 | 1000×562 | 672×314 | 같되 좁게 |
| 세운 손전화 | 470×980 | 458×280 | 지도 → 고을 → 탭, 위에서 아래로 |

- **세로 판에서는 명령 단추가 셋씩 두 줄**로 접히고, 수치도 넷씩 두 줄이 됩니다.
  「한 해를 보낸다」는 오른쪽 아래 — 엄지가 닿는 자리입니다.
- **창이 화면보다 넓으면 화면에 맞춰 접습니다.** 680짜리 사건 창이 470 화면에서
  잘려 나가던 것을 고쳤습니다. 글월이 더 여러 줄로 접히면 창 높이도 같이 늡니다.
- **「고을 바로 선택」**은 판 밖에 남는 자리가 있을 때만 뜹니다. 눕힌 손전화에서
  위쪽 표시줄을 덮고 있던 것을 고쳤습니다. 세로 판은 아래 62를 비워 둡니다.
- 세력 표는 **「보기」 단추 앞에서 멈춥니다** — 단추 밑으로 기어들어 가지 않습니다.

손가락으로 되는 것을 하나하나 확인했습니다.

```
○ 지도에서 고을을 눌러 고른다        ○ 두 손가락으로 지도를 당긴다 (2.0 → 5.0배)
○ 개간 단추가 손가락에 듣는다        ○ 지도를 끌어 옮긴다
○ 오른쪽 판이 손가락으로 굴러간다     ○ 끌고 난 뒤에 고을이 덜컥 바뀌지 않는다
○ 세로 판에서 고을 고르개가 뜬다      ○ 단추가 손가락에 넉넉하다 (모두 28px 이상)
```

판을 굴리다 손끝이 판 밖으로 나가도 **처음 짚은 판이 굴림을 받습니다.**
예전에는 그 순간 굴림이 사라졌습니다.

### 동맹

`동맹을 맺었는데 바로 약속 깨고 공격하더라` — 실제로 그랬습니다.
사이가 해마다 제 값으로 되돌아가는데 **동맹이라고 예외가 아니어서**,
60에서 맺은 동맹이 열 해쯤 지나 35 아래로 떨어지면 조용히 깨졌습니다.

| | 전 | 후 |
|---|---|---|
| 동맹 중 사이의 바닥 | 없음 (제 값까지 내려감) | **46** |
| 깨지기 전 알림 | 없음 | 44 아래로 내려가면 **한 번 알림** |
| 깨진 직후 | 바로 칠 수 있음 | **세 해 휴전** |
| 동맹의 값어치 | 치지 않는 것뿐 | **원병을 보냄** |
| 양쪽과 동맹 | 됨 | 한쪽과 맺으면 다른 쪽은 막힘 |

```
해     사이   동맹
1392    62     ○      ← 맺는다
1403    51     ○      (예전에는 여기서 깨졌다)
1417    47     ○
```

**원병**은 동맹의 값어치를 처음으로 눈에 보이게 만듭니다.
사이가 좋을수록 많이 오고, 전선의 규모에 맞추어 옵니다.

```
규슈 → 경상남도    이길 낌새  79%
같은 싸움, 명과 동맹     21%    (원병 5,616)
```

### 그 밖에

- 제목 화면이 세로 판에서 **가운데에 앉습니다** (위쪽에 몰려 있었습니다).
- 좁은 판에서 고을 수치 줄이 판 밖으로 삐져나가 **민심 막대가 옆 판에**
  그려지던 것을 고쳤습니다.
- 기록 창의 「돌아간다」가 기록이 없을 때 **가운데**에 섭니다.
- 0.5.0 세이브를 그대로 읽습니다.

## v0.5.0 — 가르쳐 주는 판

기능은 늘었는데 **처음 잡은 사람이 무엇부터 눌러야 하는지 알 길이 없었습니다.**
탭이 여섯이고 눈금이 스물인데, 1392년에 화면이 열리면 아무도 아무 말을 해 주지
않습니다. Space만 누르다 1600년쯤 망합니다. 이번 판은 그것을 고쳤습니다.

### 이번 해에 할 일

판을 읽어 **무엇을, 왜** 를 짚어 줍니다. 대신 해 주지는 않습니다 —
고르는 것이 이 놀이인데 길잡이가 골라 버리면 놀이가 없어집니다.

1392년 첫 화면에서 실제로 뜨는 것:

```
[급함] 수령 없는 고을이 16곳
       수령이 없으면 어지러움이 절로 오르고 세도 덜 걷힌다. 신하 탭에서 한 번에 채운다.
[급함] 곡식이 한 해를 못 넘긴다
       모자라면 굶고, 군대가 흩어지고, 온 고을이 시끄러워진다.
[주의] 국경 2곳이 위태롭다
       가장 급한 곳은 경상남도. 규슈가 치면 85%로 진다.
       무로마치와의 사이를 올려 두면 먼저 물지 않는다 — 사신이 성보다 싸다.
       명과 통상을 열 수 있다 · 정책 자리가 3 비었다 · 등용 대기 6명
```

국정 탭 맨 위에 서고, 고을을 고르지 않았을 때는 아래 판에도 가장 급한 하나가
뜹니다(**「지도에서 고을을 고르시오」** 만 적혀 있던 자리입니다).
누르면 그 고을이나 그 탭으로 갑니다.

**늑대를 부르지 않습니다.** 명은 늘 우리보다 셉니다. 그것만으로 겁을 주면
길잡이가 못 미덥게 됩니다. 사이가 좋거나 조약이 있으면 센 이웃도 당장의
위험으로 세지 않고, 여러 곳이 걸려도 한 줄로 묶습니다.

### 난이도

이웃이 제대로 싸우게 되면서 **배우기 전에 죽는 판**이 생겼습니다.
판을 통째로 무르게 만드는 대신 고르게 했습니다. 제목 화면에서 정합니다.

| | 이웃의 기세 | 어지러움 | 시작 국고 | 수령만 챙긴 판이 버틴 해 |
|---|---|---|---|---|
| **순한맛** | ×0.55 | ×0.75 | ×1.35 | 1815년 |
| **보통** | ×1.00 | ×1.00 | ×1.00 | 1639년 |
| **매운맛** | ×1.55 | ×1.25 | ×0.80 | 1550년 |

### 비어 있던 해를 채웠다

못박힌 사건은 서른넷뿐이라 **1453년 다음이 1498년**이었습니다.
그사이 마흔다섯 해는 결산 창만 넘겼습니다.

해가 정해지지 않은 **세 갈래 물음 20가지**를 더했습니다. 시대와 지금 형편이
맞을 때 찾아오고, 한 번 겪으면 쉰다섯 해가 지나야 다시 옵니다.
문벌의 청 · 남해의 돛 · 표류해 온 사람들 · 광맥 · 서원 · 암행어사 ·
철도 · 유학 · 공장의 밤 · 서울로만 간다 …

이제 **평균 5.7해에 한 번** 무언가를 고르게 되고,
스물다섯 해 넘게 아무것도 뜨지 않는 구간이 **없습니다**.

효과도 넓혔습니다 — 연구 · 어지러움 · 명/일본과의 사이가 선택지에 붙습니다.

### 그 밖에

- **조사를 제대로 붙입니다.** `'함경북도이(가)'` 처럼 괄호를 치고 넘어가던 자리를
  받침을 보고 갈라 적습니다(`이가` · `은는` · `을를` · `과와`).
- `node tools/sim.mjs --diff 0` 으로 난이도별로 재 볼 수 있습니다.

## v0.4.2 — 싸움의 셈을 바로잡다

"병력이 사만인데 상대 일만사천에게 성이 쉽게 밀린다"는 제보를 받고
그 장면을 그대로 만들어 재 보니, **셈이 둘로 갈라져 있었습니다.**

**1. 이웃은 싸우지 않고 그냥 가져갔다.**
플레이어가 칠 때는 주사위를 던지고 양쪽이 피를 흘리고 질 수도 있었는데,
이웃이 칠 때는 `공격 > 방어×1.25` 한 줄을 넘기면 **주사위도 손실도 없이**
고을이 넘어갔습니다. 이웃은 지지도 않고 다치지도 않았습니다.

**2. 두 쪽이 서로 다른 식을 썼다.**
플레이어의 공격에는 수령의 군무 · 병종 · 바닷길 · 정책이 들어가는데
이웃의 공격은 맨 `병력 × 기술`뿐이었고, 성곽은 이쪽이 ×0.14, 저쪽이 ×0.16이었습니다.
**화면에 보여 주는 「이길 낌새」와 이웃이 판단하는 수가 아예 다른 식**이었습니다.

**3. 「이길 낌새 %」가 이길 확률이 아니었다.**
화면에는 `공격/(공격+수비)`를 적어 놓고, 판정은 양쪽에 주사위를 곱해
큰 쪽이 이기게 했습니다. 주사위 폭(0.85~1.15 대 0.9~1.1)이 좁아
**1.45배 앞선 싸움이 「59%」로 적히는데 사백 번 붙여 사백 번 이깁니다.**

### 고친 것

싸움을 **한 함수로 모았습니다**(`warPower` · `winChance` · `resolveBattle`).
누가 걸든 같은 식, 같은 주사위, 같은 피입니다. 이웃도 이제 **집니다.**
적어 둔 낌새가 곧 이길 확률입니다 — 사백 번 붙여 확인했습니다(69% → 69%).

  1대1 50%   1.25대1 60%   1.5대1 68%   2대1 82%   3대1 92%

**그리고 내 고을이 얼마로 버티는지 보이게 했습니다.**
위 표시줄의 「군사」는 나라 전체 합이라, 고을 하나가 얼마로 지키는지는
어디에도 없었습니다. 사만을 가지고도 성이 밀리는 것처럼 보인 까닭입니다.
이제 고을을 고르면 **수비**가 맨 앞에 서고, 맞댄 이웃이 이길 낌새가 반을
넘으면 **「위태롭다」** 가 붉게 뜹니다. 짚으면 병력 · 원군 · 지형 · 성곽 · 병종이
어떻게 곱해졌는지 그대로 적어 줍니다.

| 평안북도 (성곽 4, 요동의 1.4만이 마주 본다) | 지키는 힘 | 요동이 이길 낌새 |
|---|---|---|
| 병력 2,500 | 10,180 | 69% |
| 병력 6,000 | 17,681 | 40% |
| 병력 10,000 | 26,254 | 22% |
| 병력 15,000 | 36,970 | 12% |

국경에 군사를 두면 버팁니다. 나라 전체의 사만이 아니라 **그 고을의 병력**이
지킵니다.

## v0.4.1 — 스무 해 만의 통일을 막다

1414년에 통일이 되었다는 제보를 받았습니다. 시뮬레이터에 **밀어붙임**이라는
두는 법을 더해 재 보니, 사람이 작정하고 두면 정말로 그렇게 됩니다.
까닭이 셋이었습니다.

**1. 명이 제 평형의 9%로 판을 열고 있었다.**
v0.3.0에서 수비병 셈을 고쳤으면서 **시작 병력은 옛 셈(`ri(800,3000)`)에 남겨** 두었습니다.

| | 1392년 시작 | 스스로 기르는 평형 | |
|---|---|---|---|
| 요동 | 1,386 | 16,319 | **8%** |
| 만주 | 2,285 | 32,910 | **7%** |
| 명 전체 | 27,517 | 291,856 | **9%** |
| 조선 전체 | 33,787 | 28,450 | 119% |

요동이 천삼백으로 판을 열고 다섯 해 뒤에야 만육천이 됩니다.
**그 다섯 해가 통일의 지름길**이었습니다. 이제 모든 고을이 평형에서 시작합니다.

**2. 싸움을 국고로 살 수 있었다.**
정무를 다 써도 **별칙**으로 값을 치르면 계속 칠 수 있었습니다.
돈만 있으면 한 해에 열 번도 쳤습니다. 이제 **싸움만은 별칙으로 살 수 없습니다** —
별칙은 조정이 지쳐도 돈으로 밀어붙이는 손이지만, 군사를 일으키는 일은
조정이 정해야 합니다. 다른 명령은 그대로 별칙으로 됩니다.

**3. 이쪽만 한 해에 여러 번 쳤다.**
이웃은 한 해에 한 번만 군사를 냈습니다. 이제 **전쟁 중에는 세 번까지** 밀어붙이고,
빼앗긴 제 땅이 많을수록 더 자주 냅니다.

### 재어 본 결과 (밀어붙임, 여덟 판)

서른 고을에 닿은 판이 **여덟 중 하나**이고, 그것도 **1619년**입니다.
그 판마저 1991년에 도읍을 잃고 한 고을만 남았습니다.
여덟 판 가운데 완주는 하나, 점수는 가장 잘해야 476점 —
두루 챙긴 판(1220점)의 절반이 못 됩니다.

정복은 **되기는 하지만 지는 길**입니다.

## v0.4.0 — 소리와 움직임

육백 년이 걸린 전쟁이 칠 한 번 바뀌는 것으로 끝났습니다.
그러면 그 전쟁은 일어나지 않은 것과 같습니다. 이번 판은 그것을 고쳤습니다.

### 소리 — 음원 파일 없이

이 놀이는 **파일 하나로 돌아가는 것이 규칙**이라, 소리도 그 자리에서 만들어 씁니다
(Web Audio). 내려받을 것도, 서버도 없습니다.

악기는 넷입니다. **북**(가죽과 낮은 울림), **징**(어울리지 않는 배음을 겹쳐 길게),
**뜯는 줄**(가야금·거문고 — 톱니를 낮은 거름으로 훑어 내립니다),
**피리**(숨소리를 섞고 떨림을 줍니다).

- **효과음 19가지** — 개간 · 장시 · 축성 · 모병 · 진휼에 각각 다른 소리가 붙습니다.
  한 해를 보내면 북이 울고, 사건이 걸리면 징이 웁니다.
  싸움에는 북이 다섯 번 몰아치고 쇳소리가 겹칩니다.
- **배경음** — 가락을 적어 두지 않았습니다. **오음계**(평조·계면조)에서 몇 음을 골라
  느리게 놓습니다. 같은 판이 두 번 나오지 않습니다.
  - **시대마다** 빠르기 · 높이 · 피리 섞임 · 북이 다릅니다.
    조선 전기는 성기고 느리며, 임진왜란에는 북이 들어오고, 산업화에서 걸음이 빨라집니다.
  - **형편을 따릅니다.** 전쟁 중이거나 민심이 무너지면 평조에서 **계면조**로 내려앉고
    북이 반드시 울립니다.
- 메뉴 → **소리** 에서 각각 켜고 끄고 크기를 정합니다. 설정은 남습니다.

브라우저는 사람이 한 번 누르기 전에는 소리를 내주지 않습니다.
첫 누름에서 깨우고, 깨우지 못해도 놀이는 그대로 돕니다.

### 움직임 — 전쟁이 보인다

침공이 이제 **차례를 두고 일어납니다.** 한꺼번에 터뜨리면 무슨 일이 있었는지
읽을 틈이 없습니다.

| 때 | 무엇이 |
|---|---|
| 0.0초 | 군사가 **건너갑니다** — 흐르는 점선과 화살촉, 북소리 |
| 0.6초 | **부딪힙니다** — 먹이 튀듯 열네 갈래, 고을이 통째로 번쩍이고 화면이 흔들립니다 |
| 0.9초 | **「요동 함락」** 이 크게 떠올랐다 사라집니다. 잃은 병력도 함께 |
| 이후 | 빼앗긴 땅의 **빛이 천천히 넘어오고**, 불탄 자리에 연기가 오릅니다 |

이겼을 때와 물러났을 때의 빛깔·소리가 다릅니다.
반란과 편입에도 같은 겹이 붙습니다.
명령에도 붙습니다 — 개간하면 「개간」이, 모병하면 「+2,000」이 그 고을에서 떠오릅니다.

흔들림은 **지도만** 흔듭니다. 판과 단추까지 흔들면 누르기가 어려워집니다.

창이 뜰 때도 **커지며 나타납니다.** 덜컥 튀어나오면 무슨 창인지 읽을 틈이 없습니다.

이 겹은 **규칙에 손대지 않습니다.** 판정은 이미 끝난 뒤에 보여 주기만 합니다.

### 그 밖에

- 제목 화면의 **기록** 단추가 저장 칸 화면을 띄우고 있었습니다. 이제 기록을 띄웁니다.
- 저장은 **판이 올라가도 계속 읽습니다**(`SAVE_OK`). 판을 올릴 때마다 남의 판을
  버리게 하면, 판을 올리기가 무서워집니다.

### 새로 생긴 것

**외교 — 이웃이 사람이 되었다.**
명과 일본에 **사이(친교)** 가 생겼습니다. 사신을 보내 올리고, 세폐를 바쳐 사고,
국서로 꾸짖어 깎습니다. **통상 조약**을 맺으면 고을의 특산이 팔리고,
**동맹**을 맺으면 그 나라가 우리를 치지 않을 뿐 아니라 우리를 친 쪽을 뭅니다.
남의 고을을 치면 그 자리에서 **전쟁**이 열리고, 화친에는 값이 듭니다.
사이가 무너지면 조약은 저절로 끊어집니다 — 종이는 마음을 붙들지 못합니다.

**기술 나무 — 눈금 하나가 네 갈래 스무 마디가 되었다.**
농정 · 상공 · 군기 · 학문. 해마다 **연구**가 쌓이고, 쌓인 것으로 마디를 엽니다.
가지마다 앞의 마디를 열어야 다음이 열리고, 넷을 다 가질 수는 없습니다.
마디마다 하는 일이 적혀 있고 **적힌 그대로 계산합니다** — 구황작물은 흉년 피해를 실제로 절반으로 줄입니다.

**특산 — 고을이 무엇을 내는가.**
개성은 인삼, 경상북도는 철, 강소는 비단, 유구는 중계 교역품.
안에서는 장사에 곱해지고, **밖으로는 통상 조약이 있어야 값이 됩니다.**
쇄국을 펴면 인삼이 아무리 좋아도 고을의 물건일 뿐입니다.

**병종 — 시대가 바뀌면 싸우는 방식이 바뀐다.**
창검군에서 조총병, 별기군, 기계화군까지. 수군 고을은 판옥선을,
목마 고을은 기병을 냅니다. 침공 전에 **이길 낌새를 몇 %인지 미리 보여 줍니다.**

**정통(正統) — 화면에만 있던 숫자가 일을 하게 되었다.**
v0.2.0에서 정통은 사건 선택지에 오르내리기만 하고 아무 데도 쓰이지 않았습니다.
이제 민심을 밀고, 사화의 빈도를 정하고, 고을이 등을 돌리기까지 참는 햇수를 정하고,
시대 성적에 들어갑니다. 세폐는 평화를 사 오지만 그 값을 여기서 치릅니다.

**기록 — 끝난 판이 남는다.**
세이브는 판이 바뀌면 버려지지만 기록은 남습니다. 제목 화면에서 열 판까지 봅니다.

**지도 — 당겨 보고, 끌어서 옮긴다.**
동아시아 전체를 한 화면에 담으면 정작 다스리는 땅이 손톱만 했습니다.
지도 창은 888×480으로 옆으로 길고 한반도는 68×128로 세로로 길어서,
배율을 하나로 못 박아 두면 어떻게 잡아도 고을이 작습니다.
그래서 배율을 플레이어에게 넘겼습니다.

- **휠**을 굴리면 짚은 자리를 붙들고 당깁니다 (1배 ~ 8배).
- **끌면** 지도가 따라옵니다. 손가락 두 개로도 당깁니다.
- **한반도 / 동아시아** 단추와 `F` 키로 두 자리를 오가고, `＋` `－` 로도 됩니다.

기본은 한반도가 창 높이에 꼭 차는 3.5배입니다.
가장 작은 고을인 개성이 1배에서 5×6픽셀이던 것이 3.5배에서 18×20,
8배에서 43×48이 됩니다.
확대해도 우리 고을 이름만 크게 쓰고 이웃 이름은 작게 두어,
요동과 평북이 붙어 한 낱말로 읽히지 않게 했습니다.
고른 고을은 이름표에 테를 둘러 표시합니다.
전쟁·인접 판정은 예전 논리 지도를 그대로 쓰므로 **규칙은 하나도 달라지지 않았습니다.**

**누른 것과 끈 것을 가른다.**
예전에는 누르는 순간 판정했습니다. 그러면 지도를 끌 때마다 시작한 자리의
고을이 덜컥 골라집니다. 이제 **뗄 때** 판정하고, 그사이 움직였으면 끈 것으로 봅니다.
단추도 같은 규칙이라 누른 뒤 밖으로 끌면 취소됩니다.

**작은 화면과 손가락.**
좁은 섬을 손가락으로 찍기는 어렵습니다. 이제 이름표에서 가장 가까운 고을을 먼저 잡고,
잡는 반경은 손가락이냐 마우스냐와 화면이 얼마나 줄어 있느냐에 따라 달라집니다.
작은 화면에서는 캔버스 밖에 **고을 바로 선택** 상자(44px)가 떠서 목록에서 고를 수 있고,
화면 읽기 프로그램에도 지금 무엇을 골랐는지 알립니다.

**헤드리스 시뮬레이터.**
`node tools/sim.mjs` 로 그림 없이 육백 년을 돌립니다.
`--ui` 는 모든 화면을 한 번씩 그려 보고, `--save` 는 저장했다 불러와 흘린 것이 없는지 봅니다.

**전쟁 — 정복이 남는 장사가 아니게 되었다.**
1466년에 중국과 일본을 다 먹을 수 있었습니다. 까닭은 하나였습니다 —
수비병을 채우는 셈이 **조선 고을에만 돌고 있었습니다**(`if(P.nat==='kor')`).
이웃 고을은 해마다 주사위로 육십에서 이백사십만 늘었습니다.
그래서 인구 사백만의 명나라 고을이 사천 남짓으로 지키고,
인구 오십만의 조선 고을이 삼만오천을 모아 밀고 들어갈 수 있었습니다.

- **수비병 셈이 모든 나라에 같이 돕니다.** 다만 인구에 곱절로 늘지는 않습니다 —
  옛 왕조는 인구를 다 병사로 세울 수 없었습니다. 이제 명의 고을은 만이 넘게 지킵니다.
- **원군.** 큰 나라의 고을은 혼자 서 있지 않습니다. 이웃한 제 나라 고을이
  군사를 보냅니다(지키는 쪽 30%, 치는 쪽 20%). 한 고을씩 떼어 먹는 동안
  나머지가 구경만 하던 일이 없어집니다.
- **모병 상한**을 인구의 5%에서 3%로 낮췄습니다.

**점령지 — 빼앗은 날부터 내 땅인 것은 아니다.**
빼앗은 고을은 **점령지**입니다. 세와 곡식이 절반만 걷히고, 어지러움이
해마다 절로 오르고, 다스리는 데 손이 곱절로 듭니다. 수출도 되지 않습니다.
수령을 두고 어지러움을 눌러 두면 한 해에 한 살씩 편입이 진행되어
**마흔다섯 해 뒤에 본토**가 됩니다. 어지러움을 오래 두면 **제 나라로 돌아섭니다.**

**과대팽창.** 지고 갈 수 있는 점령지는 본토가 튼튼한 만큼입니다(본토 다섯에 하나).
넘치면 넘친 만큼 해마다 민심과 정통이 깎이고 온 고을이 시끄러워집니다.
정무도 이제 **본토에서만** 늡니다 — 예전에는 빼앗을수록 정무가 늘어
정복이 정복을 불렀습니다.

**이웃의 경계.** 조선이 커질수록 사이가 떨어지고, 남의 땅을 쥐고 있으면
그 나라와는 원수가 됩니다. 빼앗긴 제 땅은 **기어이 되찾으려 합니다.**

### 고친 것

**1592년의 사건 하나가 영영 뜨지 않았다.**
그해에는 「부산 앞바다의 돛」과 「바다와 들에서」 둘이 걸려 있는데,
코드가 `find` 로 하나만 집고 나머지를 버렸습니다. 이제 줄을 세워 차례로 묻습니다.

**불러오면 조용히 처음으로 돌아가던 것들.**
사건 이력 · 별칙 · 고른 고을 · 보던 탭이 저장되지 않았습니다.
이제 저장하고 불러와도 그대로입니다 (`node tools/sim.mjs --save` 로 확인합니다).

**적어 두고 쓰지 않던 것들.**
`res`(연구) 태그는 안동과 한성에 적혀 있었으나 어디에도 쓰이지 않았습니다 — 이제 연구를 밉니다.
`개발`은 화면에 떠 있었으나 플레이어가 올릴 방법이 없었습니다 — 이제 개간 · 장시 · 축성이 함께 올립니다.

**'국고 -4'가 4전인지 4%인지 알 수 없었다.**
사건 효과에서 국고 · 곡식 · 군사는 몫(%)이고 민심 · 기술 · 정통은 눈금입니다.
이제 미리보기에 `%` 를 붙여 갈라 적습니다.

## v0.2.0 에서 고친 것

**1. 질 수 있게 됐다.**
예전 코드는 침공 대상에서 조선을 문자 그대로 배제해 두었습니다(`q.nat!=='kor'`).
이제 명·일본은 국력을 견주어 약한 쪽을 뭅니다. 조선이 흔들리면 조선을 뭅니다.
도읍(한성)을 잃으면 그 자리에서 끝납니다.
어지러움 88 이상이 다섯 해 이어진 고을은 조정을 등집니다 — 다만 한 해에 하나까지,
그리고 세 해째에 미리 경고합니다.

**2. 정무(政務) — 한 해에 쓸 수 있는 손.**
예전에는 돈만 있으면 한 턴에 백 번도 눌렀습니다. 그러면 선택이 사라집니다.
이제 한 해에 3~6번(시대에 따라)만 움직일 수 있습니다.
비용도 이미 올린 만큼 비싸지고, 시대가 오르면 물가도 오릅니다.

**3. 연말 결산.**
한 해를 보내면 세입·세출(군/녹봉/성곽/정책)·국고·곡식(거둠/먹음/썩음)·인구·민심(수령 배치율까지)·기술과
그해에 있었던 일을 표로 보여줍니다. 보이지 않으면 배울 수 없습니다.

**4. 사건이 삼지선다가 됐다.**
34개의 역사 사건에 각각 세 갈래를 두었고, 고르기 전에 효과를 미리 보여줍니다.
`1` `2` `3` 키로도 고릅니다. '알겠다' 버튼은 결정이 아닙니다.

**5. 화면에 띄운 숫자가 전부 판정에 들어간다.**
- **식량** — 군대와 백성이 실제로 먹습니다. 모자라면 굶고, 남으면 썩습니다(곳간 상한).
- **기술** — 이웃과 견주어 성적이 매겨지고, 전투 배율에 들어갑니다. 나라가 크고 편안할수록 늡니다.
- **민심** — 수령 배치율·어지러움·충성·정책이 함께 밉니다. 무너지면 고을이 떨어져 나갑니다.
- **충성** — 나라 형편을 따라 제자리를 찾아갑니다. 바닥으로 굴러떨어지지 않습니다.

**6. 정책 20가지, 설명과 코드가 일치한다.**
모든 정책에 **얻는 것(＋)과 잃는 것(－)**을 나란히 적었고, 적힌 그대로 계산합니다.
실학과 예치, 쇄국과 개화·수출주도처럼 함께 쓸 수 없는 짝을 두었습니다.
의무교육은 열 해 뒤, 연구개발은 다섯 해 뒤에 열매가 옵니다.

**7. 신하가 실존 인물이다.**
정도전 · 하륜 · 황희 · 이순신 등 54명이 생몰년에 맞춰 등장하고, 각자 기질과 말투가 있습니다.

**8. 조정의 일.**
고을을 고르지 않아도 되는 명령 — 기술 진흥 · 내탕금 · 인재 초빙.
후반에 쓸 데 없이 쌓이던 국고가 여기로 흘러갑니다.

**9. 시대 성적표.**
시대가 바뀔 때마다 성적을 매깁니다. 혼자만의 숫자가 아니라 **명·일본과 견주어** 매깁니다.
끝나면 여덟 시대의 성적을 한 장에 놓고 봅니다.

**10. 지도가 동아시아 모양이 됐다.**
Natural Earth의 실제 행정구역과 해안선을 42개 게임 지방으로 묶었습니다.
음영 지형 위에 국경과 정치색을 얹고, 왼쪽 위 단추나 `M` 키로 **지형/정치 지도**를 바꿉니다.
전쟁·인접 판정은 기존 논리 지도를 그대로 써서 게임 규칙과 새 화면을 분리했습니다.
인구도 땅 넓이만 보지 않습니다 — 1392년의 명은 조선보다 훨씬 많이 살았습니다.

**11. 오른쪽 판이 굴러간다.**
정책 20가지, 신하 전원, 기록 60줄을 휠(또는 손가락 끌기)로 봅니다.

### 조작

| | |
|---|---|
| 지도에서 고을 누르기 | 고른다 |
| 지도 왼쪽 위 **지형/정치** | 지도 표현을 바꾼다 |
| 지도 오른쪽 위 **한반도/동아시아** | 지도 범위를 바꾼다 |
| 지도 위에서 **휠** / 손가락 두 개 | 짚은 자리를 붙들고 당긴다 (1~8배) |
| 지도를 **끌기** | 지도를 옮긴다 |
| **고을 바로 선택** | 목록에서 조선의 고을을 정확히 고른다 (판 밖에 자리가 있을 때 뜹니다) |
| 지도의 **깃발** 누르기 | 군을 고른다 — 갈 수 있는 고을이 빛난다 |
| 군을 고른 채 **맞닿은 고을** 누르기 | 그리로 보낸다 |
| 아래 단추 | 명령 (정무를 씁니다) |

## 손보는 데 쓰는 것

```
node tools/sim.mjs              # 다섯 가지 두는 법으로 육백 년을 돌린다
node tools/sim.mjs --plan conquer   # 정복만 노려 얼마나 먹을 수 있는지 잰다
node tools/sim.mjs --plan wedge     # 같은 손에 이간만 더하면 얼마나 달라지는지 견준다
node tools/sim.mjs --runs 8         # 판을 여덟 번씩 — 씨앗 흔들림을 줄인다
node tools/sim.mjs --trace      # 스물다섯 해마다 한 줄씩 찍는다
node tools/sim.mjs --ui         # 모든 화면을 한 번씩 그려 본다
node tools/sim.mjs --save       # 저장했다 불러와 흘린 것이 없는지 본다
node tools/sim.mjs --seed 7     # 씨앗을 고정해 같은 판을 다시 본다
node tools/sim.mjs --diff 0     # 난이도 (0 순한맛 · 1 보통 · 2 매운맛)
```

그림 없이 놀이 논리만 돌립니다. 규칙을 고칠 때마다
"정말 이길 수도 질 수도 있는가"를 눈이 아니라 숫자로 확인하기 위한 것입니다.
